# EuroSAT Land Cover Classification using Deep Learning

## Project Overview
This project uses deep learning techniques to classify satellite images into land cover categories using the EuroSAT RGB dataset.

## Problem Statement
Can deep learning accurately classify satellite land cover images for environmental monitoring?

## Dataset
EuroSAT RGB Dataset

Dataset Source:
https://github.com/phelber/eurosat

## Classes
- Forest
- River
- Highway
- Residential
- Agricultural
- Industrial
- Pasture
- Sea/Lake
- Herbaceous Vegetation
- Permanent Crop

## Technologies Used
- Python
- TensorFlow
- OpenCV
- NumPy
- Matplotlib

## Model
CNN Model

## Results
- Final Training Accuracy: 83.11%
- Final Validation Accuracy: 80.67%
- Validation Loss: 0.5505

## Applications
- Environmental monitoring
- Climate analysis
- Disaster management
- Land classification

## Future Scope
Integrating wildfire prediction and real-time satellite intelligence systems.
